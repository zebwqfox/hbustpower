# 湖科电量 隐私政策

生效日期：2026年9月22日
版本：1.9.4

湖科电量（以下简称"本应用"）是一款由个人开发者独立开发的宿舍电量查询工具，有 Android 与 iOS 两个版本，本政策同时适用于两者。本应用**不会把你的账号、宿舍号、电量数据上传给开发者**。与开发者站点有关的联网行为只有两项：读取版本与公告文件（第五条，只读不传），以及匿名使用统计（第六条，默认开启，**在首次启动引导页上、开始使用之前就能关掉**）。请在使用前阅读本政策，尤其是加粗内容。

## 一、我们不收集什么

除第六条所述的匿名使用统计（你可以在同意本政策前或之后随时关闭）外，开发者**不收集、不存储、不共享**你的任何信息。本应用没有账号体系，没有第三方统计或广告 SDK。无论是否开启统计：

- **永远不会**收集你的学号、姓名、手机号、身份证号、位置、通讯录、短信、相册，以及 IMEI / OAID / Android ID（Android）或 IDFA / IDFV / 序列号（iOS）等设备识别码。
- **永远不会**收集你的宿舍号、剩余电量、用量与充值记录——这些只在你的手机上显示。
- 不会收集你的学习通账号和密码（见第二条）。
- 不会生成用户画像、不做个性化推送、不做定向广告。

## 二、账号与密码如何处理

查询宿舍电量需要使用学校指定的**超星学习通**账号完成身份验证。

- 你在本应用登录页面输入的账号和密码，**只会被直接填入超星官方登录页面（https://passport2.chaoxing.com）的输入框并由该官方页面提交**，用于完成官方身份验证。
- 本应用**不保存密码**，不写入本机存储，不写入日志，也不会发送给开发者或任何第三方。关闭登录页面时输入内容即被清除。
- 验证码、二次验证、修改弱密码、找回密码等环节全部在超星官方网页内完成，本应用不参与。
- 超星学习通如何处理你的信息，适用其自身的隐私政策。

## 三、本机保存的信息

以下信息仅保存在你的手机本机，卸载应用即被删除，开发者无法访问：

| 内容 | 用途 | 存储方式 |
|---|---|---|
| 学校电费系统的授权链接 | 下次打开时免重复登录 | Android：Keystore 加密后存入应用私有目录；iOS：系统钥匙串（`AfterFirstUnlockThisDeviceOnly`） |
| 学校站点的会话 Cookie | 维持登录状态、读取电量 | 系统 WebView / WKWebView 的 Cookie 存储（应用私有） |
| 低电量提醒阈值、是否已完成首次引导、是否已同意本政策 | 保存你的设置 | 应用私有配置文件 |
| 最近一次读取到的宿舍号、剩余电量、更新时间 | 通知与界面展示 | 应用私有配置文件 |
| 本次运行的诊断日志（最多 60 条） | 排查问题 | 仅内存，关闭应用即清空，不含账号、密码、授权链接或 Cookie 内容 |

本应用已关闭系统自动备份（`allowBackup="false"`），上述数据不会随云备份离开设备。

## 四、数据来自哪里，发往哪里

本应用只与下列域名通信，全部为学校或学校指定服务商的官方地址：

- `auth.chaoxing.com`、`passport2.chaoxing.com`：超星学习通官方身份验证。
- `ecard.hbust.edu.cn`：湖北科技学院一卡通门户（授权跳转、校园卡余额）。
- `xianankd.hbust.edu.cn`：学校宿舍电费系统（剩余电量、用量、充值记录）。

此外，为了告诉你有没有新版本，本应用还会访问开发者自己的站点：

- `hbustelec.imfurry.com`：读取一个固定的版本与公告文件（详见第五条）。
- `cdn-imfurry.imfurry.com`：你点击"去下载"后，由浏览器从这里下载安装包。
- 匿名使用统计保持开启时，还会向 `hbustelec.imfurry.com` 发送第六条列出的内容；关闭后不发送。

读取到的电量数据只显示在你的设备上，不经过开发者的任何服务器，也不出境传输。

## 五、检查更新与公告

为了在学校系统改版、或应用出现已知问题时能够通知到你，本应用会读取一个放在开发者站点上的**静态文件**，内容只有最新版本号、更新说明、下载地址、一条公告文字和几个功能开关。

- **只读取，不上传。** 这是一个普通的 GET 请求，不携带 Cookie，不携带账号、宿舍号或设备识别码。为避免 CDN 缓存导致刚发布的公告、功能开关或版本信息无法及时生效，请求地址会附带一个名为 `cacheBust` 的当前时间戳参数；该参数只表示请求发生的时间，不包含用户或设备信息。该路径的服务器访问日志已关闭，**不记录、不存储请求来源 IP**，所以开发者无法从中得知是谁读取了这个文件。
- **什么时候发生。** 你同意本政策之后，应用**每次启动时检查一次**；回到前台时也会检查，但**最多每 30 分钟一次**；此外只有你在 设置 → 更新 中手动点击"检查更新"时才会发生。之所以每次启动都查，是因为这个文件也用来在学校页面改版时及时关掉出问题的功能入口，等一天就失去意义了。
- **这个请求有多大。** 带 `ETag`，内容没变时服务器只回一个 304，实际传输约几百字节。
- **不会自动下载或安装。** 发现新版本时只弹出提示，点"去下载"会跳转到你手机的浏览器，由你自行下载安装。**本应用不具备、也不会执行任何形式的代码热更新。**
- **下载地址受限。** 只接受 HTTPS，且域名必须是应用内置允许的地址，避免该文件被篡改后把你引导到陌生页面。
- **公告只是文字。** 公告可以关闭，关闭记录只保存在本机；公告也会在设定的时间之后自动消失。
- **功能开关只能关闭本应用自己的界面入口**（例如学校某个页面改版后暂时隐藏校园卡入口），不会下发任何可执行内容，也不会改变本政策承诺的数据处理方式。
- 该文件读取失败时，应用一切照常，所有功能保持开启。
- 你可以在 设置 → 调试与诊断 中看到这个地址，以及上次检查的时间。

## 六、帮助改进（匿名使用统计）

这一项**默认开启**，但开关就摆在首次启动引导里、你点「同意并继续」（Android）或「开始使用」（iOS）之前的那一屏上——**在同意本政策之前就可以把它关掉**，关掉后本应用不会生成任何标识、也不会发送任何内容。开始使用之后，也可以随时在 **设置 → 帮助改进** 中关闭（两个版本都有这一项）。**关闭完全不影响任何功能。**

保持开启时，应用**每天最多一次**（与第五条的更新检查不同，这一项仍然是每天一次）向 `hbustelec.imfurry.com` 发送下列内容，此外不发送任何东西：

| 内容 | 例子 | 为什么需要 |
|---|---|---|
| 安装标识 | `3f2504e0-4f89-11d3-9a0c-0305e82c3301` | 一个**由本应用随机生成**的编号，用于区分"同一台手机的多次上报"和"多台手机"。它不来自任何硬件信息，无法反推设备或身份 |
| 应用版本 | `1.9.3 (193)` | 判断新版本铺开了多少，决定旧版本还要支持多久 |
| 系统版本 | `Android 14 (API 34)` / `iOS 18.2` | 决定还要兼容到哪个系统版本 |
| 设备型号 | `Xiaomi 23127PN0CC` / `Apple iPhone16,2` | 排查只在某些机型上出现的问题 |
| 处理器架构 | `arm64-v8a`（仅 Android） | 同上 |
| 语言 | `zh-CN` | 同上 |
| 渠道 | `release` | 区分正式版与调试版 |

关于这项统计：

- **看得见。** 设置 → 帮助改进 → "看看会上报什么"，逐项列出上面这些内容的真实取值。
- **关掉就没了。** 关闭时本机保存的安装标识会一并删除，之后不再发送任何内容；再次开启会生成一个新的标识，与之前的记录无法关联。
- **可以换号。** 在同一个页面可以随时"重置安装标识"。
- **不做画像。** 这些数据只用于统计版本分布与机型分布，不用于识别个人、不做用户画像、不做推送或广告、不向任何第三方提供、不出境。
- **不记 IP。** 服务端不记录、不存储请求来源 IP，也不把访问日志与上报数据关联。
- **可以删除。** 把你的安装标识（在上面那个页面可以看到）发到 `zebwqfox@vip.qq.com`，开发者会删除与之对应的全部记录。

## 九、通知

## 十一、你的权利

- **撤回登录授权**：设置 → 账户 → 清除登录信息，会删除本机保存的授权链接与 Cookie。
- **关闭提醒**：在系统设置中关闭本应用的通知权限。
- **不看公告与更新提示**：公告可直接关闭；更新提示可选择"跳过这个版本"。
- **关闭统计**：首次启动引导页，或此后的 设置 → 帮助改进；关闭后本机安装标识随即删除，不再发送任何内容。
- **删除已上报的统计**：把你的安装标识发到 `zebwqfox@vip.qq.com`，开发者会删除对应的全部记录。
- **删除全部数据**：卸载应用即可，开发者处没有你的任何数据副本。
- **查阅本政策**：设置 → 关于 → 隐私政策，随时可查看当前版本。

除第六条所述的匿名统计外，开发者不持有你的任何数据，因此无法提供"导出""更正"等需要服务端配合的操作；统计数据本身不含可更正的个人内容，可直接要求删除。
