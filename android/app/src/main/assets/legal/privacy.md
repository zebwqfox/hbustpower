# 湖科电量 隐私政策

生效日期：2026年9月22日
版本：1.9.0

湖科电量（以下简称"本应用"）是一款由个人开发者独立开发的宿舍电量查询工具。本应用没有自己的服务器，不会把你的任何信息上传给开发者。请在使用前阅读本政策，尤其是加粗内容。

## 一、我们不收集什么

开发者**不收集、不存储、不共享**你的任何个人信息。本应用没有后台服务器、没有账号体系、没有统计或广告 SDK，因此：

- 不会收集你的学号、姓名、手机号、身份证号、位置、通讯录、短信、相册、设备识别码（IMEI/OAID/Android ID）。
- 不会收集你的学习通账号和密码（见第二条）。
- 不会生成用户画像、不做个性化推送、不做定向广告。

## 二、账号与密码如何处理

查询宿舍电量需要使用学校指定的**超星学习通**账号完成身份验证。

- 你在本应用登录页面输入的账号和密码，**只会被直接填入超星官方登录页面（https://passport2.chaoxing.com）的输入框并由该官方页面提交**，用于完成官方身份验证。
- 本应用**不保存密码**，不写入本机存储，不写入日志，也不会发送给开发者或任何第三方。关闭登录页面时输入内容即被清除。
- 验证码、二次验证、修改弱密码、找回密码等环节全部在超星官方网页内完成，本应用不参与。
- 超星学习通如何处理你的信息，适用其自身的隐私政策。

## 三、本机保存的信息

以下信息仅保存在你的手机本机，卸载应用即被删除，开发者无法访问：

| 内容 | 用途 | 存储方式 |
|---|---|---|
| 学校电费系统的授权链接 | 下次打开时免重复登录 | Android Keystore 加密后存入应用私有目录 |
| 学校站点的会话 Cookie | 维持登录状态、读取电量 | 系统 WebView Cookie 存储（应用私有） |
| 低电量提醒阈值、是否开启离线演示、是否已完成首次引导、是否已同意本政策 | 保存你的设置 | 应用私有配置文件 |
| 最近一次读取到的宿舍号、剩余电量、更新时间 | 通知与界面展示 | 应用私有配置文件 |
| 本次运行的诊断日志（最多 60 条） | 排查问题 | 仅内存，关闭应用即清空，不含账号、密码、授权链接或 Cookie 内容 |

本应用已关闭系统自动备份（`allowBackup="false"`），上述数据不会随云备份离开设备。

## 四、数据来自哪里，发往哪里

本应用只与下列域名通信，全部为学校或学校指定服务商的官方地址：

- `auth.chaoxing.com`、`passport2.chaoxing.com`：超星学习通官方身份验证。
- `ecard.hbust.edu.cn`：湖北科技学院一卡通门户（授权跳转、校园卡余额）。
- `xianankd.hbust.edu.cn`：学校宿舍电费系统（剩余电量、用量、充值记录）。

读取到的电量数据只显示在你的设备上，不经过开发者的任何服务器，也不出境传输。

## 五、权限说明

本应用只申请两项权限，均可拒绝，拒绝后不影响核心功能以外的使用：

| 权限 | 用途 | 拒绝的后果 |
|---|---|---|
| 网络访问（INTERNET） | 读取学校系统的电量、用量、充值记录与校园卡余额 | 无法查询真实数据，仍可使用离线演示 |
| 发送通知（POST_NOTIFICATIONS，Android 13 及以上） | 电量低于你设定的阈值时提醒一次 | 不再收到低电量提醒，其他功能正常 |

本应用**不申请**位置、相机、麦克风、通讯录、短信、电话、存储、后台定位、读取应用列表等权限，也不在后台持续定位或常驻监听。

## 六、第三方 SDK

本应用未集成统计、广告、推送等会收集个人信息的第三方 SDK。随应用打包的开源组件如下，均在本机运行、不联网上传数据：

| 名称 | 提供方 | 用途 | 是否收集个人信息 |
|---|---|---|---|
| AndroidX / Jetpack Compose | Google | 界面框架、生命周期、窗口适配 | 否 |
| Kotlin 标准库与协程 | JetBrains | 语言运行时 | 否 |
| jsoup | jsoup.org | 解析学校网页的 HTML | 否 |
| Backdrop、Shapes | Kyant0（开源） | 界面材质绘制组件（当前版本已打包但未启用） | 否 |
| desugar_jdk_libs | Google | 兼容旧系统的日期时间 API | 否 |

## 七、通知

低电量提醒由你的设备本地生成：应用在启动、回到前台或你手动刷新时读取电量，若低于设定阈值则发出一次本地通知。**不使用任何第三方推送服务，不会有推广或营销通知。**

## 八、未成年人

本应用面向在校学生，不专门收集未成年人信息。若你是未满 14 周岁的未成年人，请在监护人指导下使用。

## 九、你的权利

- **撤回登录授权**：设置 → 账户 → 清除登录信息，会删除本机保存的授权链接与 Cookie。
- **关闭提醒**：在系统设置中关闭本应用的通知权限。
- **删除全部数据**：卸载应用即可，开发者处没有你的任何数据副本。
- **查阅本政策**：设置 → 关于 → 隐私政策，随时可查看当前版本。

由于开发者不持有你的数据，无法提供"导出""更正"等需要服务端配合的操作。

## 十、政策更新

本政策如有变更，会在应用内以弹窗形式再次征得你的同意，并更新页首的生效日期与版本号。
