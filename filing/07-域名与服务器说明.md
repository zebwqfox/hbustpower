# 没有自有服务器时，备案怎么填

本应用是纯客户端：没有后端服务器，没有账号体系，所有数据直接来自学校官方系统并只保存在用户手机上。备案表单里却普遍有"服务器 IP""域名"这类必填项，下面是可行的处理方式。

## 一、事实描述（可直接用于说明栏）

> 本应用为纯客户端工具，开发者未部署任何服务器，不接收、不存储用户数据。应用运行时仅访问湖北科技学院及其指定身份验证服务商（超星）的官方站点读取用户本人数据，数据仅显示在用户设备本机。开发者仅持有一个用于展示隐私政策与应用介绍的静态网站。

## 二、需要准备的域名

即便没有业务服务器，实际办理中仍建议准备一个**自己的域名 + 已完成网站 ICP 备案的静态站点**，原因：

1. APP 备案通常需要通过"接入服务提供者"（云厂商）提交，平台会核验你在该平台有可关联的网络资源。
2. 应用商店上架普遍要求隐私政策提供**公网可访问链接**。
3. 备案通过后的备案号，通常也要求在官网与应用内展示。

最小成本方案：

- 注册一个域名（`.com` / `.cn` 均可，`.cn` 须实名）。
- 在国内云厂商买最低配的对象存储或轻量服务器托管静态页面。
- 先完成**网站 ICP 备案**（备案主体与 APP 备案主体保持一致），再提交 **APP 备案**。
- 把 `filing/html/privacy-policy.html` 和 `user-agreement.html` 上传上去，链接填进备案表与商店后台。

## 三、表单填写建议

| 表单项 | 建议填法 |
|---|---|
| 服务器放置地 | 中国内地（静态站点所在地区）`【待填】` |
| 服务器 IP / 实例 | 静态站点的 IP 或对象存储所在实例 `【待填】` |
| 域名 | 你的已备案域名 `【待填】` |
| 域名证书 | 域名注册商提供的证书文件 `【待填】` |
| 是否使用 CDN | 按实际情况；用了 CDN 要选对应的接入服务商 |
| 应用数据存储说明 | 见上文"事实描述" |

## 四、不要做的事

- 不要为了凑表单而虚构服务器或填写他人资源。
- 不要把学校的域名（`hbust.edu.cn`）或超星的域名填成"本应用的域名"——那不是你的资源，主体不符会被驳回，也可能给学校带来麻烦。
- 不要在未取得学校同意的情况下，宣传本应用为学校官方应用。
