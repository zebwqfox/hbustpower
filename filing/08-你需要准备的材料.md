# 只有你本人能准备的材料

以下内容涉及实名身份与账号操作，必须由你本人完成，不要委托他人代填，也不要把证件照片、口令、验证码发给任何人（包括我）。

## 一、身份与联系方式

- [ ] 身份证原件（正反面照片，办理时在平台上传）
- [ ] 本人手机号（接收短信核验，建议实名归属与身份证一致）
- [ ] 常用电子邮箱（与隐私政策中的联系邮箱一致）
- [ ] 通信地址
- [ ] 人脸核验（多数平台的 App 端当场完成）

## 二、账号

- [ ] 接入服务商账号（阿里云 / 腾讯云 / 华为云等，需已实名认证）
- [ ] 域名注册商账号
- [ ] 各应用商店开发者账号（如计划上架）

## 三、域名与网站

- [ ] 已注册域名（`.cn` 需实名）
- [ ] 域名证书（注册商后台可下载）
- [ ] 静态站点或服务器实例（用于托管隐私政策页面）
- [ ] 完成**网站 ICP 备案**（主体与 APP 备案一致）

## 四、应用相关

- [ ] 正式签名密钥库 `hbustpower-release.jks` 与口令（按 `06-签名与指纹.md` 生成并备份）
- [ ] 用正式签名打出的 release APK
- [ ] `签名信息.txt`（运行脚本生成）
- [ ] 应用图标（`assets/app-icon-1024.png`）
- [ ] 应用截图 4–5 张（建议包含首页、用量、充值记录、校园卡与设置）
- [ ] 隐私政策与用户协议的公网链接

## 五、上架商店可能额外要求

- [ ] **软件著作权证书**：华为、小米、OPPO、vivo、应用宝均要求；中国版权保护中心办理，正常约 30–60 个工作日，可加急。
- [ ] **学校相关证明**：应用名称或功能涉及具体学校时，部分商店会要求学校出具的授权或说明函。
- [ ] **测试说明**：如商店要求登录后审核，提供仅用于审核的学习通测试账号。
- [ ] **备案号**：2023 年 9 月后，国内商店上架普遍要求先完成 APP 备案。

## 六、时间预期（仅供参考，以实际受理为准）

| 环节 | 大致时长 |
|---|---|
| 域名实名 | 1–3 个工作日 |
| 网站 ICP 备案 | 1–20 个工作日（省通管局审核） |
| APP 备案 | 接入商初审 1–3 个工作日 + 管局审核约 1–20 个工作日 |
| 软著 | 30–60 个工作日（加急可缩短） |
| 商店审核 | 1–7 个工作日 |

## 七、提醒

- 备案信息必须与实际安装包一致：包名、版本、签名任一不符都可能被驳回或在后续抽查中被撤销。
- 备案通过后，应用内需展示备案号：把备案号填入 `android/app/src/main/res/values/strings.xml` 的 `icp_filing_number` 并重新打包。
- 任何平台都不会通过聊天工具索要你的密钥库口令或短信验证码；遇到此类要求一律拒绝。
