# 湖科电量 · 移动应用备案材料包

本目录是为"湖科电量"Android 应用办理**移动互联网应用程序备案（俗称 APP 备案 / ICP 备案）**准备的材料。

> **先说清楚边界**：备案必须由主体本人在接入服务商（云厂商或分发平台）的平台上实名提交，需要身份证、人脸核验、手机号短信验证。这些步骤我无法代做，也不应由他人代填。本目录提供的是**可以提前准备好的部分**：应用信息、隐私政策、用户协议、权限与 SDK 清单、签名信息提取工具、合规自查表。最终以你选择的接入平台的表单要求为准。

## 目录

| 文件 | 用途 |
|---|---|
| `01-应用基本信息.md` | 备案表单逐项填写内容（含待你补全的占位项） |
| `02-权限与SDK清单.md` | 权限用途说明、第三方 SDK 目录，应用商店与备案都会要 |
| `03-隐私政策.md` | 隐私政策正文（应用内与网页版的唯一来源） |
| `04-用户协议.md` | 用户服务协议正文 |
| `05-合规自查表.md` | 对照监管要求的自查结果，附整改状态 |
| `06-签名与指纹.md` | 生成正式签名、导出"应用公钥 / 签名 MD5"的步骤 |
| `07-域名与服务器说明.md` | 本应用无自有服务器时，备案里该怎么填 |
| `08-你需要准备的材料.md` | 只有你本人能提供的证件与账号清单 |
| `html/` | 隐私政策、用户协议的网页版，用于挂在已备案域名上 |
| `签名信息.txt` | 运行提取脚本后生成（未生成时不存在） |

## 办理顺序建议

1. **先确认主体与名称**（见 `08`）：个人备案的应用名称若含学校简称，可能被要求提供说明或改名，建议先想好备用名称。
2. **准备域名**：注册一个域名并完成**网站 ICP 备案**（不是 APP 备案），用来托管 `html/` 里的隐私政策。应用商店上架普遍要求隐私政策有公网链接。
3. **生成正式签名密钥**（见 `06`），用它打出 release 包，并导出公钥与 MD5。
4. **在接入服务商平台提交 APP 备案**：填 `01` 的内容，上传图标、截图、签名信息。
5. **拿到备案号后**：把备案号填进 `android/app/src/main/res/values/strings.xml` 的 `icp_filing_number`，重新打包；关于页会自动显示该备案号。
6. **上架应用商店**：各商店还会单独要求软著、隐私政策链接、测试账号等，见 `08`。

## 代码侧已经完成的合规改动

- 包名改为 `com.zebwqfox.hbustpower`（原包名 `cn.edu.hbust.power` 使用了学校域名，不宜作为个人备案主体的包名）。
- 首次启动先弹《隐私政策》《用户服务协议》同意页；**未同意前不联网、不申请任何权限**，点"不同意并退出"直接退出应用。
- 应用内可随时查看两份文本：设置 → 关于，或关于页底部入口；文本由本目录同步生成，不会与备案材料不一致。
- 关于页预留备案号展示位，填入 `icp_filing_number` 后显示。
- release 构建从 `keystore.properties` 读取正式签名；密钥与口令不进版本库。

## 文本改动方式

隐私政策和用户协议**只改本目录下的 Markdown**，然后执行：

```bash
python android/tools/sync-legal.py
```

会同时更新应用内资源和 `html/` 网页版。若改动涉及收集范围等实质内容，把 `LegalDocuments.CONSENT_VERSION` 加 1，老用户会再次看到同意页。
